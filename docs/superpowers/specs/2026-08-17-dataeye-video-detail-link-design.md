# DataEye 视频链接稳定化设计

## 目标

修复 DataEye 临时 MP4 地址过期后出现 `403 Forbidden` 的问题，同时继续遵守“网站不下载、不保存、不内嵌视频”的既定范围。

## 方案

- DataEye 测试素材的“打开视频”链接直接指向该素材在 AdXray 的精确详情/播放页面。
- 保留来源页字段用于数据追溯；当视频入口与来源入口为同一地址时，详情页只显示一个按钮，避免重复。
- 不再把带临时鉴权参数的 `adxvideo.dataeye.com` 地址写入网站数据。

## 验收标准

- 素材列表和详情页的“打开视频”都指向 `https://adxray.dataeye.com/index/home#/Product/Plan/4147966400000`。
- 页面中不再出现已失效的 `adxvideo.dataeye.com` 地址。
- 详情页不会为同一个地址同时显示“打开视频”和“打开原始广告”。
- 仅进行本地构建与必要测试，不提交、不上传、不部署。
