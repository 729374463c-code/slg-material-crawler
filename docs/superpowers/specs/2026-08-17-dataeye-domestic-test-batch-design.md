# DataEye 国内素材独立测试批次设计

## 目标

在现有 SLG 竞品吸量素材网站中新增一个独立的 DataEye 国内素材测试批次，用一条《三国志·战略版》广告验证国内素材数据的展示、详情查看、表格导出和跨页面切换能力。

## 数据边界

- 测试批次与现有海外周榜分开，不参与海外素材排名和周次统计。
- 数据来源标记为 DataEye ADXray。
- 精确来源页使用素材计划详情页：`https://adxray.dataeye.com/index/home#/Product/Plan/4147966400000`。
- 视频使用 DataEye 当前提供的临时直链，并明确标注可能过期；网站继续只提供外链，不嵌入或保存视频。
- 只展示吸量侧指标，不把 DataEye 的预估转化量并入现有指标体系。
- 无法通过页面信息确认的创意画面与制作信息标记为“待视频复核”，不作无依据推断。

## 页面行为

1. 周次选择器新增“国内素材测试 · DataEye”，并显示来源与数据日期。
2. 素材列表展示一条《三国志·战略版》记录。
3. 详情页展示 DataEye 投放指标、精确详情页入口和临时视频入口。
4. Excel 导出沿用现有分组表格结构，并导出该测试批次当前可确认的数据与初步脚本判断。
5. 对比页在当前批次不足两条素材时显示空状态，不渲染不完整的双素材对比控件。
6. 周度复盘使用该批次的一条记录正常生成，但明确其为测试数据集。

## 验收标准

- 可从周次选择器切换到独立 DataEye 测试批次。
- 列表只出现一条测试素材，且不会覆盖任何历史海外素材。
- 点击素材可进入详情页，精确来源链接指向指定 DataEye 素材计划页。
- 页面中不存在视频播放器。
- 对比页在单条素材场景下显示明确提示。
- 自动化测试和生产构建通过。
- 仅完成本地预览；未经用户确认不提交远端或部署。
