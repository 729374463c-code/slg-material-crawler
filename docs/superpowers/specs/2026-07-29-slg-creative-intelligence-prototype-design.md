# SLG 海外吸量素材 Demo 需求

## 1. Demo 目标

先用约 5 条 SLG 竞品素材做一版内部 Demo，验证团队能否通过统一拆解和吸量数据对比，更直观地判断哪些素材方向值得关注。

本次只验证核心思路，不建设完整的素材管理系统。

## 2. Demo 展示什么

Demo 只包含三个核心页面。

### 素材总览

- 展示约 5 条 SLG 竞品素材；
- 显示产品、地区、平台、素材缩略图和核心标签；
- 支持按产品、地区、平台和钩子类型简单筛选；
- 可以选择素材进入详情或对比。

### 素材详情

- 播放或预览素材；
- 展示素材的统一拆解结果；
- 展示同一素材在不同地区或平台的版本；
- 展示对应的吸量数据。

### 素材对比

- 选择 2–3 条素材并列查看；
- 对比前 3 秒钩子、第一画面、卖点、玩法展示和制作方式；
- 对比不同地区、平台的吸量表现；
- 记录一条简单的本周观察结论。

## 3. 素材拆解内容

每条素材只保留 Demo 演示需要的字段：

| 类型 | 字段 |
|---|---|
| 基础信息 | 产品名、公司、地区、平台、题材、素材时长 |
| 创意拆解 | 前 3 秒钩子、第一画面、核心卖点、是否展示结果、是否有角色、是否有口播、是否有实机、是否使用假玩法 |
| 制作方式 | 实机录屏、3D 动画、真人剧情、2D 动效、AI 生成、混合制作、可玩广告 |
| 表现数据 | 吸量数据、统计时间、地区、平台 |

同一创意在不同地区或平台投放时，作为同一条母素材下的不同版本展示。

## 4. 数据准备

- 素材视频、素材信息和吸量数据由业务人员提供；
- 吸量数据由业务人员从广大大等渠道检索；
- Demo 只展示吸量侧数据，不展示转化率和商业价值指标；
- 数据直接预置在 Demo 中，不做自动抓取、批量导入或后台录入。

## 5. Demo 使用流程

```text
查看 5 条素材
   ↓
打开素材详情，了解统一拆解
   ↓
选择 2–3 条素材进行对比
   ↓
结合吸量数据记录一条观察结论
```

## 6. 本次不做

- 登录、成员和管理员权限；
- 素材新增、编辑、审核和发布流程；
- 自动抓取第三方数据；
- 批量导入；
- 自动识别视频或自动打标签；
- 自动计算素材评分；
- 转化率、ROAS、收入和付费率；
- AI 自动生成结论或创意 Brief；
- 大规模素材库和复杂后台。

## 7. Demo 验收

满足以下四点即可认为 Demo 跑通：

1. 可以查看约 5 条 SLG 素材；
2. 可以进入详情查看素材拆解和吸量数据；
3. 可以选择 2–3 条素材进行横向对比；
4. 可以基于对比结果记录一条简单观察结论。

本次交付以完成以上四项演示为终点。
