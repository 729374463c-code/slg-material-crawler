# SLG 竞品吸量素材网站：后续能力升级路线

## 1. 当前基础

网站已经具备以下可用能力：

- 本周 Top 10 SLG 素材台账；
- 产品、平台、热度、投放天数、展示估值、地区和卖点标签展示；
- 视频原始页与广大大精确详情页跳转；
- 创意拆解、制作方式、脚本总结、结构节奏和情绪曲线；
- 任意两条素材手动对比；
- 按参考表格结构导出 Excel；
- 周度数据自动汇总与复盘视图。

## 2. 建议升级顺序

| 阶段 | 能力 | 目标 | 实施边界 |
| --- | --- | --- | --- |
| 第一阶段 | 周度复盘 | 自动汇总当前素材的标签、钩子、Top 素材和本周结论 | 已在本地版本实现，不依赖外部服务 |
| 第二阶段 | 数据质量检查 | 自动检查关键字段、视频链接和广大大详情页是否齐全 | 已在本地版本实现，链接检查当前为格式检查 |
| 第三阶段 | 对比结论增强 | 根据选中的两条素材自动总结吸量、标签、投放周期和钩子差异 | 已在本地版本实现，不替代人工判断 |
| 第四阶段 | 历史周归档 | 保存每周快照，并支持按周查看趋势与往期 Top 素材 | 下一批可实施 |
| 暂缓 | 飞书导出 | 把投放数据、标签和脚本规律写入指定飞书表格 | 按当前决定暂不实施 |
| 暂缓 | 周一自动任务 | 每周一上午自动采集、解析并生成待复核周报 | 按当前决定暂不实施 |

## 3. 推荐的数据流

`广大大 MCP → 本周候选池 → 去重与链接校验 → 视频解析 → 人工复核 → 正式素材库 → 周度复盘/Excel/飞书`

核心原则：未经人工复核的数据不自动发布到正式网站；公开网页不直接连接广大大 MCP，也不保存账号凭证。

## 4. 下一阶段需要一次确认的关键问题

进入第二、三阶段前，仅需要集中确认以下事项：

1. 候选池和审核结果放在哪里：随 Git 项目保存，还是接入共享数据库；
2. 每周任务运行位置：本地常开电脑、云函数或独立服务器；
3. 飞书导出目标：普通电子表格还是多维表格，以及由谁提供应用授权；
4. 自动任务失败后通过什么方式通知负责人。

在这些问题确认前，网站仍可继续使用现有静态数据、手动更新和 Excel 导出，不影响当前 Demo。
