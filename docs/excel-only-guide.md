# 广告素材调研：只交付 Excel

本指南适用于无需更新网站的独立研究任务。先按 [README](../README.md) 配置数据来源；不需要启动网站。采集权限与素材再分发权限由使用者自行确认。

## 一、每批先写清楚的口径

| 项目 | 必填内容 |
| --- | --- |
| 产品 | 游戏名称、别名、核对后的平台产品 ID；是否包含联运版本、多个投放产品 |
| 来源与市场 | 广大大 / ADXray；国内 / 指定海外国家；两来源分开保留 |
| 渠道 | 纳入、排除哪些媒体；是否排除 B 站 |
| 曝光 | 平台预估曝光/展示估值门槛，严格大于还是大于等于；不足时能否降低 |
| 天数 | 平台累计使用/投放天数门槛；不要用起止日期相减代替 |
| 日期 | 检索区间，以及末次投放是否必须达到指定日期；“今天”写成确切日期 |
| 数量 | 每款目标多少个独立创意组，而不是多少条重复投放记录 |
| 排序 | 按曝光、热度或其他指标；多指标须指定优先顺序，不能临时编权重 |
| 视频分析 | 是否需要卖点、制作方式、脚本总结和时间段结构；无法读取时如何标注 |

历史批次的“100万、30天”“持续到7月”等要求不是默认条件。放宽标准必须得到授权，并在对应记录的备注中标明原门槛及实际值。不要为凑数纳入其他产品、无关热点或重复创意。

## 二、采集和分析

1. 读取本批要求及平台工具说明。核对游戏身份、主产品与联运关系；关键词命中不等于目标产品。
2. 验证一条完整记录，再验证 3–5 条小批量，确认字段单位、翻页、排序和登录态。ADX 一次只发一个请求，保持一个账号、一个页面。
3. 按平台分页收集候选，并保存广告 ID、来源及采集时间。仅查完第一页不能断言没有素材；达到足够的合格独立创意数，或检查完可访问结果后停止。
4. 先做硬条件筛选，再检查视频主体和参考价值。查看完整主体内容；只比文件名、URL 或开头截图不能完成去重。
5. 同主体仅更换开头、字幕、比例、落版、地区的素材归入同一创意组。主体拼接仍高度相同的，结合片段顺序判断并记录依据；主体玩法或叙事明显不同的不要强行合并。
6. **视频归组，数据不合并：**同组每个广告 ID 的平台、地区、日期、曝光独立保留。代表视频选可访问且清晰的一条，不把多个版本的曝光相加。
7. 两步分析：先采集平台事实；再读取视频，填写卖点、制作方式和脚本分析。平台已有标签可作为来源明确的初稿，不能冒充逐帧分析。没有视频、音轨或完整观看证据时标注相应限制，不臆造时间点、口播或 AI 制作结论。
8. 使用 ExcelJS、openpyxl 等实际生成 `.xlsx`，重新读取核对记录数、数值和超链接，并检查至少一个游戏工作表的排版后交付。

## 三、Excel 文字范本

### 工作表结构

- `说明`：本批日期、筛选条件、数据来源、单位、去重方法、实际独立创意数和分析限制。
- 每个游戏一张工作表：用于阅读，对同组的产品、代表素材及脚本分析纵向合并；各条投放数据不合并。
- `投放明细`：所有记录逐行展开，**不合并单元格**，每行带创意组 ID 和广告 ID；供筛选、排序和核验。
- 游戏名称超过 Excel 工作表名称限制或包含非法字符时使用简写，并在“说明”中记录全称。

### 游戏工作表表头

第 1 行：合并全宽，写“产品名｜来源｜市场｜采集日期｜本批筛选标准”。这里只写当前批次的实际条件。

第 2 行：分组表头。第 3 行：字段名。第 4 行起：数据。

| 分组 | 列 | 字段 | 填写规则 |
| --- | --- | --- | --- |
| 产品信息与素材 | A | 产品名称 | 平台原名，可附中文名 |
| 产品信息与素材 | B | 基础信息 | 公司、上线日期等已核实信息；缺失写未提供 |
| 产品信息与素材 | C | 代表素材详情页 | 可点击链接，广大大详情或 ADXray 详情；同组可合并 |
| 数据信息 | D | 组内排名 | 按本批约定排序；同组多行共享排名 |
| 数据信息 | E | 来源平台 | 广大大或 ADXray |
| 数据信息 | F | 广告平台 | 抖音、YouTube 等完整媒体名，自动换行 |
| 数据信息 | G | 热度 | 平台原值；不支持该指标则写未提供 |
| 数据信息 | H | 累计投放天数 | 平台原值，单位天 |
| 数据信息 | I | 预估曝光/展示估值 | 数字单元格，显示 K/M；来源口径不得混淆 |
| 数据信息 | J | 投放开始日期 | YYYY-MM-DD |
| 数据信息 | K | 末次投放日期 | YYYY-MM-DD |
| 数据信息 | L | 投放地区 | 平台返回范围，不从语言猜地区 |
| 卖点与制作 | M | 一级标签 | 如核心玩法、美术与题材、福利 |
| 卖点与制作 | N | 二级标签 | 如模拟经营、角色展示、抽卡福利；与一级对应 |
| 卖点与制作 | O | 制作方式 | 实机、2D动效、真人、混合等；注明判断依据 |
| 脚本规律 | P | 脚本总结 | 开头吸引点、主体卖点、体验承诺及结尾承接 |
| 脚本规律 | Q | 结构与节奏 | 按实际视频时间段写内容与功能，不机械套模板 |
| 脚本规律 | R | 情绪变化 | 如压力→成长→释放；标明属于内容分析推断 |
| 核验信息 | S | 创意组 ID | 本批稳定唯一编号，例如 G001 |
| 核验信息 | T | 广告 ID | 来源平台原始 ID，按文本存储防止精度丢失 |
| 核验信息 | U | 本条广告详情页 | 每条投放记录自身的精确链接，不以代表链接代替 |
| 核验信息 | V | 采集日期 | YYYY-MM-DD，可附时区及时间 |
| 核验信息 | W | 备注与核验状态 | 合并理由、低于门槛、视频/音轨未核验等 |

C 是同组代表素材，U 是每条投放记录的追溯链接；只有一条记录的组两者可相同。若需精简阅读表，可隐藏 U，投放明细仍必须保留。不要无意义地并列两列相同的“ADX详情页”。

### 样式

- 产品表头深蓝、数据表头蓝色、卖点表头浅青、脚本表头红色；产品内容浅黄、脚本内容淡黄，其他数据浅色分隔。
- 同一创意组用轻微底色区分，不以醒目颜色暗示未经证实的效果优劣。
- 冻结前 3 行和前 2 列。产品列建议 18–22 字符、链接列 20–24、媒体列 26–32、日期列 14、脚本列 45–60；全表自动换行、顶部对齐。
- 合并仅用于阅读表。自动筛选主要放在未合并的“投放明细”，避免排序破坏分组。
- 曝光保留原始数值，如 `1500000`，通过 Excel 数字格式显示为 `1.50M`。例如：

```text
[>=1000000]0.00,,"M";[>=1000]0.00,"K";0
```

- 缺失数据用“未提供”或空值并在备注解释，不填 0；真实 0 可以保留。不要把 `1.50M` 字符串作为唯一数值来源。
- 链接必须写入 Excel 超链接属性，显示“查看广大大详情”或“查看ADXray详情”；不使用平台首页或短期签名 CDN 视频地址冒充详情页。详情页也可能需要登录，不承诺免登录永久播放。
- 若只有平台数据，P–R 写“待视频核验”及具体限制，不生成看似完整的虚构分析。基础信息中的下载量等没有可靠来源也不补猜测。

## 四、交给 AI 的完整指令

替换方括号内容后直接发送。平台接入成功并不代表工具已具备视频理解能力；如果无法分析视频，应先交付有证据的数据并明确缺口。

```text
在当前仓库执行一次仅 Excel 的广告素材调研。
先读取 README.md、docs/excel-only-guide.md；
若使用 ADX，再读取 docs/adx-collection-lessons-2026-09-18.md。

产品：[产品及别名]
来源：[ADXray / 广大大 / 两者]
市场：[中国大陆 / 指定地区]
媒体：[纳入渠道；排除渠道]
素材类型：视频
日期范围：[起止日期]
末次投放要求：[无 / 不早于某日]
累计投放天数：[门槛或无]
曝光门槛：[门槛及严格比较方式]
目标数量：每款 [数量] 个独立创意组
排序：[第一指标；第二指标]
不足时：[实际交付不足数量 / 已授权的具体放宽规则]
是否纳入联运、多产品广告：[是/否及判断范围]

使用已配置且有权限的数据工具。ADX 单账号、单页面、串行请求；
先验证1条，再验证3–5条，不要反复切换浏览器或自动重试登录。
验证码或权限问题交给我处理。

先采集投放事实，再读取视频分析。相同主体仅换开头、版式、
地区等归为同组，代表视频合并，各广告数据分行保留，不相加曝光。
保留平台广告详情页，不用会失效的签名视频直链。
分析包括卖点标签、制作方式、脚本总结、结构节奏及情绪变化；
无法核验的内容明确标注，不编造。

按上述指南的表头和样式生成真实 .xlsx：
每游戏独立表、说明表、未合并的投放明细表；
曝光显示 K/M、底层保留数值，链接可点击。
重新读取验证条数、数值和超链接，检查排版后提供文件。
文件保存到我指定的本地交付目录；不要提交研究结果或凭证。
不要修改网站数据，不启动网站，不推送 GitHub，不部署。
只汇报实际独立创意数、未满足项及文件路径。
```

## 五、交付检查

- 每个游戏的独立创意数与组 ID 数一致；多投放记录不计为多个创意。
- 每条记录满足硬条件，或有明确授权及放宽备注；两平台数据不直接汇总估值。
- 详情链接逐条对应广告；抽查打开的是该广告，不是首页。
- 原始数据、内容观察和分析推断可区分；未经视频核验的不写成已分析。
- 文件为可正常打开的 `.xlsx`，无损坏、截断或数值转文本；长脚本可完整阅读。
- 文件名建议 `产品或批次_市场_来源_YYYY-MM-DD.xlsx`；新批次不覆盖旧文件。
- 临时缓存、账号信息、登录态和研究结果默认只存本地；分享前核对平台条款及敏感信息。
