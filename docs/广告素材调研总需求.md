# 游戏广告素材调研与交付：统一需求

更新日期：2026-10-20。本文件是本仓库后续工作的首要需求入口，适用于国内外游戏及广大大、ADXray 两个来源。新要求先写入本文件或当前批次记录，再采集、分析、导出；不依赖聊天记忆。

## 1. 执行入口与优先顺序

每次任务依次读取：

1. 本文件：长期业务规则、交付标准及历史决定。
2. 当前批次记录：产品、日期、数量、筛选条件、进度和用户批准的例外。
3. 按需读取 [接入说明](../README.md)、[ADX技术规程](adx-collection-lessons-2026-09-18.md)、[Excel格式范本](excel-only-guide.md)。

用户最新明确指示优先，并先更新文档。历史批次门槛不自动应用于新任务；技术文档不能覆盖业务口径。无需重新翻阅整段聊天，但事实仍需以平台数据、视频证据和当前进度为准，需求文档不能替代数据核验。

## 2. 目标、范围和交付模式

- 通过可追溯的投放数据和创意分析，帮助团队复盘、对比及寻找有参考价值的吸量方向。
- 项目起源于海外 SLG，现覆盖用户指定的国内外卡牌、休闲、模拟经营等产品，不以“不是 SLG”为由排除明确指定的游戏。
- 仅研究吸量线索，不以曝光、热度或预估转化量推导真实 CTR、转化率、收入或 ROI。
- 每批明确选择“仅 Excel”或“网站更新”。仅 Excel 不启动或修改网站，不部署、不自动上传研究数据。
- 网站修改沿现有框架，先本地预览及必要测试，再由用户确认发布；每次改动本地 Git 存档，GitHub 上传与线上部署另行授权。
- 专项与历史周次分别保存，带批次名称和日期，不覆盖旧内容。每周任务须先询问并得到确认，不默认无人值守。

## 3. 三项长期强制规则

### 3.1 视频合并成同一条，投放数据分别列出

数据分为“独立创意组”和“平台投放记录”两层，不把同一视频的多个投放记录当成多条独立素材。

- 主体镜头、玩法展示、叙事发展与结果基本相同，仅开头、字幕、比例、边框、尾板、投放地区或媒体不同，归入同一创意组。
- 少量拼接或不同广告 ID 不自动成为新创意。反之，只有开头相同、共用角色或同款游戏，也不能直接判为重复。
- 不只比较 URL、标题、封面；需比较主体镜头顺序及内容，记录合并依据与差异。不确定的继续复核或标记待核验。
- 每组保留组 ID、代表素材、全部关联广告 ID。每条记录分别保留媒体、地区、曝光、累计投放天数、起止时间、来源与详情页。
- Excel 将同组代表素材及共用分析纵向合并，后面的不同投放数据逐行列出；另附无合并单元格的“投放明细”，方便排序。
- 数量按独立创意组计算。例如一个视频有三地区投放，是 **1组创意、3条投放记录**，不是3条独立素材。
- 不简单相加组内或跨平台曝光，避免重复统计。排序若使用代表记录的值，要说明选择规则及来源。
- “再续20条”等增量任务还须与已交付历史创意组去重。

### 3.2 曝光统一带 K/M 单位

- 用户可见的表格、说明和网页曝光统一显示单位：`350K`、`1.25M`、`107.39M`；K=1,000，M=1,000,000。
- 低于1K显示为小数K或明确“次”，不能留下无单位长数字。
- Excel 底层保留原始数字，以数字格式显示单位，不能仅保存字符串而破坏排序。可使用：

```text
[>=1000000]0.00,,"M";[>=1000]0.00,"K";0"次"
```

- 门槛比较使用未四舍五入的原值；严格大于1M不包含恰好1M。
- 缺失不填0；用“未提供”或“—”并注明原因。热度、曝光、综合评分分别保留，不互相冒充。

### 3.3 广大大与 ADX 均保留具体广告详情页

- **广大大改为精确广告详情页，取代此前直链偏好；ADX保持精确广告详情页，不改回视频直链。**
- 链接必须来自真实查询并对应本条广告，不能用平台首页、泛搜索页或猜测的 ID 拼造。
- 不把短期签名 MP4 地址作为长期交付链接，不承诺详情页永久有效或免登录；订阅与登录要求应说明。
- 同组可有一个代表链接，但每条数据仍保留自身详情页以便追溯。不要重复列出两个无意义的同名链接列。
- 默认不交付下载视频包，也不嵌入播放器；用户另外明确要求时再处理。

## 4. 每批开始前固定口径

当前批次用以下模板记录到单独的本地任务文件，不把私人数据自动推送公开仓库：

```text
批次名、日期、交付模式：
产品名、别名、平台产品ID、国内/海外版本：
是否包含联运或多个投放产品：
来源平台、市场、纳入/排除媒体：
检索起止日期、末次投放要求：
累计投放天数门槛：
曝光门槛及严格大于/大于等于：
各产品目标独立创意组数、排序规则：
不足时允许放宽哪些条件、授权记录：
格式参考、分析深度：
已查页码/范围、候选去向、实际组数、证据路径：
下一步、尚待解决的问题：
```

天数采用平台累计值，不用首末日期相减替代。“持续至今天”写成确定日期。数量不足只在授权范围内向后检索、放宽，并逐条标记；不因需要凑数自动降低其他门槛。

国内与海外、两平台以及不同媒体的估值口径不得混用。若记录包含被排除媒体，不能把全媒体总估值称为“排除后”的曝光。只查过部分页面，不能声称全库没有素材或得到全库TOP。

## 5. 采集、分析与可恢复流程

1. **先整理需求，再采集。** 新口径先更新当前批次记录；验证一条完整数据，再用3–5条验证小批量。
2. 广大大使用有权限的 MCP；ADX使用当前已授权工具，网页操作优先 Playwright MCP。不把工具已连接等同于全部字段或批量采集已验证。
3. ADX严格一个账号、一个页面、串行请求；保存结果后再进行下一项，不并发翻页或视频请求。用户处理登录与验证码，不复制别的浏览器凭证或绕过访问控制。
4. 两步分析：先采集平台事实及链接，再读取视频。仅有标题、文案或标签时不能生成已确认的脚本分析。
5. 保留原始证据、标准化数据、排除理由、创意分组依据及已查范围；恢复任务从记录接续，避免反复从头采集。
6. 首次超时先检查是否已生效；同方法连续两次失败停止盲试，说明卡点。不要无声来回切换浏览器、反复登录。
7. 用户补充要求不等于停止。只有明确暂停、切换优先级或必须由用户处理的阻碍才暂停。

## 6. 数据与内容分析

投放事实至少包括：产品、来源、广告ID、详情页、媒体、热度（如有）、累计投放天数、曝光估值、投放起止日期、地区及采集时间。

内容分析包括：

- 一级/二级卖点标签，按内容选取，不批量套同一标签；
- 首画面、开头钩子、核心与辅助卖点、角色、口播、实机、画风、时长、节奏、落版、本地化；
- 制作方式：实机、2D动效、3D动画、真人、混合等；AI生成或假玩法的判断必须有证据；
- 脚本总结、实际时间段结构与节奏；情绪变化、受众判断属于研究推断，不能称为实测。

可参考“开头吸引注意→激发兴趣→满足体验欲→收获”的框架，但不强迫每条视频套同一结构。抽帧不等于完整观看，未听音轨要说明；无法读取的视频保留待核验状态，不伪造口播和时间点。

## 7. Excel交付验收

详细字段和排版遵循 [Excel独立交付指南](excel-only-guide.md)；新批次有指定模板时先读取模板，不能声称复刻了无法访问的文件。

- [ ] 每款游戏独立表，保留说明表和未合并投放明细；字段顺序、配色、换行及冻结符合约定。
- [ ] 目标数量按创意组计数；换头、地区和版式近重复已复核，合并依据可查。
- [ ] 共用素材格合并，但所有投放记录分行保留，链接与行对应。
- [ ] 曝光显示K/M或明确单位，底层为可排序数值；未把缺失填为0。
- [ ] 广大大、ADX都链接具体广告详情；没有首页或临时直链替代。
- [ ] 门槛、市场、媒体与时间范围正确，放宽处明确标记。
- [ ] 平台事实、视频观察、研究推断和未核验内容可区分。
- [ ] 输出真实可打开的`.xlsx`，复读核对组数、记录数、超链接与数值，检查脚本无截字。

只交付Excel的任务不得顺带改网站或上传素材。上述是人工/AI执行检查要求，**不是已经写入导出程序的自动校验功能**。

## 8. 历史工作结论摘要

| 阶段 | 延续的决定 | 不应继续套用的旧做法 |
| --- | --- | --- |
| 海外SLG原型 | 由样本发展为素材库、任意两素材对比、调研表和脚本分析 | 仅允许SLG、无来源转化率 |
| 广大大专项及周次 | 独立批次保存、排序和筛选口径可追溯 | 每批固定200K、30天或2026年7–8月截止 |
| 国内ADX研究 | 国内游戏、平台事实与视频分析分两步，精确详情页 | 临时视频直链、并发浏览器采集 |
| 塔塔冒险队等补充 | 数量不足可按当批授权降曝光门槛，并标记 | 自动继承旧媒体白名单或自动放宽天数 |
| 龙魂旅人、姜饼人王国等续采 | 按主体创意去重，增量与历史对照 | 换头、地区、版式变体重复计数 |
| 心动小镇链接修正 | ADX使用详情页，旧草稿不冒充新解析 | 以签名视频地址承诺长期播放 |
| 国内休闲经营及中式微恐研究 | 每游戏工作表、合并创意/分行数据、K/M、单独Excel | 将具体游戏的例外门槛应用到所有产品 |
| GitHub公开与上手文档 | 国内外、广大大与ADX双来源；自行配置账号及工具 | 认为克隆仓库即可免配置自动爬取 |

历史结果不等于本批数据，也不代表已覆盖全库。原始交付文件及凭证不因公开此需求文档而公开。
