# SLG 素材爬取与竞品广告调研

基于 **广大大（Guangdada）与 ADXray（DataEye）** 的国内外游戏广告素材调研项目，用于整理投放数据、归并相似创意、分析视频内容，并通过网站与 Excel 支持团队复盘和素材对比。

项目从海外 SLG 素材研究起步，现已扩展到国内投放，以及卡牌、休闲、模拟经营等游戏品类。仓库名称保留 `slg-material-crawler`，实际研究范围不局限于 SLG 或海外市场。

## 两个数据来源

| 数据平台 | 本项目的主要用途 | 使用前提 |
| --- | --- | --- |
| [广大大](https://guangdada.net/) | 海外游戏广告素材、展示估值、热度、媒体与地区等信息 | 配置有权限的 MCP/数据服务，按实际返回字段使用 |
| [ADXray](https://adxray.dataeye.com/) | 国内游戏广告素材、预估曝光、累计使用天数、投放周期与媒体等信息 | 有效账号及对应权限；使用当前可用的授权接口或浏览器流程 |

两平台的覆盖范围和统计口径不同，不直接合并估值，也不将跨平台排序当作统一排行榜。国内专项通常使用 ADXray，海外专项通常使用广大大；具体平台和筛选条件按每批任务确定。

## 项目包含什么

- **素材调研网站**：按批次查看素材和投放数据，筛选产品，查看结构化创意分析。
- **素材对比**：选择素材，对照开头钩子、卖点、制作方式及脚本结构。
- **表格导出**：导出投放数据与分析，便于复盘、共享和进一步整理。
- **采集与分析工作流程**：先获取平台数据及素材链接，再按需读取视频、分析并核验；历史流程记录保存在 `docs/`。

仓库中的前端展示已整理的数据，**不是无需配置即可运行的全自动爬虫服务**。平台账号、MCP 服务、浏览器登录态和分析工具需要另行配置；克隆仓库不会自动获得它们，也不会自动采集最新数据。

## 调研流程与数据规则

1. **明确本批口径**：指定产品、国内或海外、媒体渠道、时间范围、投放天数、曝光门槛和目标数量。
2. **采集投放记录**：核对产品身份，保留来源平台、广告 ID、媒体、地区、投放周期、累计使用天数、平台估值和采集日期。
3. **按创意主体去重**：相同主体仅换开头、字幕、版式、尾板或投放地区时归为同组；关联投放记录分别保留，不简单相加曝光。
4. **分析视频**：整理卖点标签、开头钩子、制作方式、脚本总结和结构节奏。情绪与受众判断标记为研究推断；抽帧分析不等同于完整观看及音轨核验。
5. **交付与复核**：按独立批次整理网站数据或 Excel，保留历史内容。阈值放宽必须明确标注，不以重复素材或无关热点凑数。

链接统一优先保留**具体广告详情页**，而非平台首页或易失效的签名视频直链。详情页仍可能要求登录或订阅，不承诺永久访问。

曝光显示使用 **K / M**（K = 1,000；M = 1,000,000），Excel 底层尽量保留可排序数值。平台预估曝光、热度和预估转化量不是同一指标；不以这些数字推导真实点击率、转化率或 ROI。

> 筛选门槛按批次确定，不存在所有游戏通用的固定“百万曝光、30天”要求。采集与发布需要人工确认，本仓库不默认开启无人值守的每周任务。

## 本地运行

准备与项目依赖兼容的 Node.js 22 LTS 和 pnpm 9 或更高版本：

```bash
git clone https://github.com/729374463c-code/slg-material-crawler.git
cd slg-material-crawler
pnpm install
pnpm dev
```

打开终端输出的本地地址。端口以实际启动日志为准。

## 测试与构建

```bash
# 单元测试
pnpm test

# Netlify 静态站点构建
pnpm build:netlify

# Netlify 构建及静态产物检查
pnpm test:netlify

# 另一套站点构建及检查
pnpm build
pnpm test:sites
```

Netlify 构建输出目录为 `dist/netlify`，对应仓库内 `netlify.toml`。以上命令只构建或检查；发布需要另行配置托管服务并授权。

## 目录导览

| 目录 | 内容 |
| --- | --- |
| `src/` | 页面、组件、素材数据与导出逻辑 |
| `data/` | 素材拆解等结构化数据 |
| `docs/` | 需求、历史设计和采集流程记录 |
| `tests/` | 构建产物等测试 |
| `build/` | 构建与预览辅助脚本 |
| `public/` | 静态资源及历史示例素材 |

ADXray 操作注意事项见 [采集与导出流程](docs/adx-collection-lessons-2026-09-18.md)。历史文档可能采用旧批次标准，执行新任务前应重新确认适用范围。

## 账号、安全与素材权利

- 遵守广大大、ADXray 的服务条款及账号权限；不绕过验证码、登录限制、付费权限或访问控制。
- 浏览器采集避免多账号、多页面或并发请求引发账号限制；遇到风险提示应停止并处理。
- 不提交账号密码、Cookie、Token、签名凭证或私有配置。公开仓库不代表第三方平台数据可以无条件再分发。
- 广告视频、游戏画面、产品名称和商标归各自权利人所有，不属于代码许可证的授权范围。使用或分享前应确认素材授权及平台条款。
- 研究结果用于创意参考；平台估值和内容分析不能替代真实投放实验。
